# [PRD] Run100 (런백) - iOS 앱 요건 정의서 & 기능 명세서
> **문서 버전:** v1.0.0  
> **타깃 플랫폼:** iOS 18.0 이상 (Target Device: iPhone 16 및 최신 iPhone)  
> **개발 프레임워크:** Swift 6, SwiftUI, SwiftData, HealthKit, WidgetKit (홈 화면 바탕화면 & 잠금 화면 위젯)  
> **핵심 철학:** 실시간 GPS 러닝 측정을 배제하고, 오직 **"월 100km 목표 누적"**과 **"데일리 기록 및 잔디 심기(습관 형성)"** 2가지 핵심 가치에만 100% 집중하는 미니멀 러닝 트래커.

---

## 1. 프로젝트 개요 (Overview)

### 1.1 배경 및 목적
- 수많은 러닝 앱(나이키 런 클럽, 스트라바 등)은 실시간 GPS 측정, SNS 피드, 복잡한 크루 기능 등으로 인해 진입 장벽이 높고 UI가 복잡함.
- 대다수 러너들은 이미 **애플 워치, 가민(Garmin) 또는 기존 피트니스 앱**으로 달리기를 측정함.
- 러너들에게 진정으로 필요한 것은 **"이번 달 100km를 채우기 위해 오늘 몇 km를 뛰어야 하는가?"**에 대한 명확한 코칭과, 매일 뛰어 채워지는 **"시각적 성취감(잔디 심기/스트릭)"**임.
- **Run100**은 측정 기능을 과감히 걷어내고, **대시보드(Dashboard)**와 **캘린더(Calendar)** 2대 핵심 화면으로만 구성된 궁극의 미니멀 100km 트래커를 지향함.

### 1.2 핵심 사용자 가치 (Core Value Proposition)
1. **월 100km 역산 코칭**: 남은 일수와 남은 거리를 계산하여 매일 부담 없는 권장 거리 제시 (예: *"남은 9일 동안 하루 3.5km만 뛰면 100km 완주!"*)
2. **원터치 기록 누적 & HealthKit 연동**: 애플 건강 앱(Apple HealthKit)의 러닝 워크아웃 데이터를 백그라운드 자동 동기화하거나 수동으로 3초 만에 기록 추가.
3. **깃허브 스타일 잔디 심기 캘린더**: 뛴 거리에 따라 채도가 달라지는 30일 히트맵 매트릭스로 매일 뛰는 연속성(Streak) 보상.
4. **iOS 홈 화면(바탕화면) 위젯 지원**: 앱을 켜지 않아도 스마트폰 홈 화면과 잠금화면에서 이번 달 진행률과 오늘 권장 러닝 거리를 상시 확인.

## 4. 데이터 모델 정의 (Data Models)

### 4.1 RunSession (단일 달리기 기록)
```swift
import Foundation
import SwiftData

@Model
final class RunSession {
    @Attribute(.unique) var id: UUID
    var date: Date                  // 운동 일시
    var distanceKm: Double          // 달린 거리 (km)
    var durationSeconds: TimeInterval // 운동 시간 (초, 선택)
    var memo: String?               // 메모/코스명 (예: 한강 탄천 러닝)
    var isManual: Bool              // 수동 입력 여부 (false: HealthKit 동기화)
    var source: String              // "AppleHealth", "Garmin", "Manual"
    var shoeId: UUID?               // 착용 러닝화 ID (로테이션 지원)
    
    init(distanceKm: Double, date: Date = Date(), durationSeconds: TimeInterval = 0, memo: String? = nil, isManual: Bool = true, source: String = "Manual", shoeId: UUID? = nil) {
        self.id = UUID()
        self.distanceKm = distanceKm
        self.date = date
        self.durationSeconds = durationSeconds
        self.memo = memo
        self.isManual = isManual
        self.source = source
        self.shoeId = shoeId
    }
}
```

### 4.2 MonthlyProgress (월간 계산 집계 모델)
```swift
struct MonthlyProgress {
    let year: Int
    let month: Int
    let targetKm: Double = 100.0
    var totalAccumulatedKm: Double
    var sessionsCount: Int
    var currentStreak: Int
    var restDaysCount: Int
    
    // 계산 프로퍼티
    var remainingKm: Double {
        max(targetKm - totalAccumulatedKm, 0.0)
    }
    
    var progressRatio: Double {
        min(totalAccumulatedKm / targetKm, 1.0)
    }
    
    var completionPercentage: Int {
        Int(progressRatio * 100)
    }
    
    var isGoalAchieved: Bool {
        totalAccumulatedKm >= targetKm
    }
    
    // 오늘 권장 거리: 남은 거리 / 남은 일수 (당월 말일까지)
    func recommendedDailyKm(remainingDaysInMonth: Int) -> Double {
        guard remainingDaysInMonth > 0 && remainingKm > 0 else { return 0.0 }
        return (remainingKm / Double(remainingDaysInMonth))
    }
}
```

## 5. 화면별 상세 기능 요건 (Screen Specifications)

앱은 하단의 **4개 탭 바(TabView - 대시보드 / 캘린더 / 히스토리 / 설정)**로 구성됩니다.

### 5.1 [Tab 1] 대시보드 화면 (DashboardView)

#### [기능 F-101] 헤더 및 월 이동/선택 인디케이터
- 현재 연/월 및 목표 표시 (예: "MONTHLY 100K", "9월 100km 대시보드")
- 불필요한 D-Day 배지를 제거하여 깔끔하고 미니멀한 헤더 타이틀 렌더링.
- **[v1.0.2] 우측 상단 월 선택기 (`< M월 >`)**:
  - 기존 설정(⚙️) 버튼이 하단 탭바로 이동하고, 상단 우측에 직관적인 월 선택 컨트롤 배치.
  - `<` (이전 달 이동 버튼): 터치 시 이전 달 대시보드 및 누적 기록 조회.
  - `M월` (월 선택 탭 메뉴): 불필요한 아래 화살표를 제거한 미니멀한 라벨. 터치 시 최근 12개월 목록이 노출되어 원하는 달로 즉시 점프.
  - `>` (다음 달 이동 버튼): 터치 시 다음 달로 이동하며, 당월을 넘어서는 미래 월은 비활성화(`disabled`) 처리.
  - **애플 건강 데이터 연동 범위**: 최근 1년(12개월) 전체 워크아웃을 동기화하여 과월(8월, 7월 등) 조회 시에도 과거 애플워치 러닝 기록이 대시보드 및 잔디 캘린더에 완벽히 노출.

#### [기능 F-102] 100km 프로그레스 링 히어로 카드 (Hero Card)
- **원형 프로그레스 링 (Circular Progress Ring)**:
  - SwiftUI `Circle().trim(from: 0, to: progressRatio).stroke(AngularGradient(...))`
  - 완주율에 따라 부드러운 스프링 애니메이션(`.animation(.spring(response: 0.6), value: progressRatio)`)
  - 링 중앙에 현재 누적 거리 (`68.0 / 100 km`) 및 달성 퍼센트 배지(`68% 달성`) 노출
- **우측 정보 카드**:
  1. `이번 달 평균 페이스 카드`: 당월 전체 러닝의 실시간 **평균 페이스(예: `5:30 /km`, `6:00 /km`)** 대형 수치 디스플레이 및 총 러닝 횟수/시간 요약 노출. (불필요한 남은 거리 정보 제거)
  2. `이번 달 평균 심박수 카드`:
     - 당월 달리기 세션들의 실시간 **평균 심박수(예: `152 bpm`)** 대형 수치 디스플레이 및 심박수 기반 운동 강도 가이드(적정 유산소/고강도 러닝 구간 등) 노출.
     - **[v1.0.5] 미니멀화**: 복잡하고 불필요한 누적 거리 그래프를 완전히 제거하고, 러너에게 가장 중요한 페이스(속도)와 심박수(강도) 듀얼 메트릭 체제로 정돈.
- **[v1.3.1] 하단 듀얼 인디케이터 바 (스트릭 & 러닝화 수명)**:
  - **좌측 스트릭 칩**: `🔥 N일 연속 >` 캡슐 칩 (터치 시 캘린더 탭으로 즉시 화면 전환).
  - **우측 러닝화 소모량 칩**: `👟 신발 이름 70% 🟡` 컬러 캡슐 칩 (터치 시 러닝화 관리 시트 즉시 팝업, 신발 미등록 시 `👟 러닝화 등록 +` 안내).
  - 별도의 긴 카드로 대시보드 공간을 차지하지 않고, 히어로 카드 하단에 콤팩트하게 통합되어 한눈에 핵심 습관과 장비 상태를 동시 파악.

#### [기능 F-103] 4레인 스타디움 레이스 트랙 & 최근 3개월 동기간 경쟁 (4-Lane Stadium Track & Past Ghost Competition)
하단의 텍스트나 외부 깃발로 인한 시각적 군더더기를 걷어내고, 실제 육상 경기장 100m 결승 트랙을 모티브로 한 **1~4번 레인 독립 스타디움 트랙**으로 개편합니다.

1. **1~4번 레인 육상 스타디움 트랙 시각화**:
   - **상단 체크포인트 룰러**: 트랙 상단에 `0k`, `25k`, `50k`, `75k`, `100k` 기준 눈금을 배치하여 직관적인 주행 페이스 가이드 제공.
   - **전 레인 트랙 두께 13pt 균일화**: 1번 레인과 2~4번 레인의 트랙 두께를 13pt로 단정하게 통일하여 시각적 안정감을 극대화하고, 당월 레인은 오렌지 테두리 글로우 효과(`Color.orange.opacity(0.35)`)로 감각적으로 강조.
   - **1번 레인 (이번 달 - 현재의 나)**: `9월` (굵은 텍스트) + 골드 그라데이션 트랙 게이지 + 오른쪽 방향으로 질주하는 러너(`🏃`, 목표 달성 시 완주 축하 `🎉`)가 실시간 위치에서 주행.
   - **2~4번 레인 (과거 3개월 - 과거의 나)**: `8월`, `7월`, `6월` (불필요한 레인 번호 제거 후 N월만 간결 표시) + 차분한 모노크롬 슬레이트 그레이 트랙 + 오른쪽 방향으로 함께 달리는 러너(`🏃`) 아이콘이 동기간(N일차) 누적 거리만큼 주행.
   - **겹침(Collision) 100% 해소**: 각 월의 기록이 독립된 레인에서 달리므로 거리가 비슷해도 아이콘이나 텍스트가 겹치지 않고 명확하게 시각화.
   - **우측 스코어보드 & 줄바꿈 방지**: 각 레인 우측에 누적 거리(폭 70pt, 100km+ 초과 달성 시 줄바꿈 방지 `.lineLimit(1)` 적용, 예: `109.7k`)와 순위 메달(🥇, 🥈, 🥉, 4위는 비움)을 일렬 정돈.
2. **목표 초과 달성(Overachievement) 위트 있는 반영**:
   - 100km 목표 달성 시 원형 링 중앙에 SF Symbols 불꽃 심볼이 적용된 **`초과달성 중`** 앰버 캡슐 배지(`flame.fill` + `초과달성 중`) 표출.
   - 트랙 헤더 우측 배지에 **`🏆 완주 (+X.Xkm)`** 형태로 초과 달성 거리 실시간 안내.
   - 과월 기록 카드 및 히스토리 성적표에도 `🏆 100km 완주 (+X.Xkm)` 보존.
3. **실시간 콤팩트 코칭 요약 & 애플 건강 동기화**:
   - 트랙 하단에 콤팩트한 코칭 메시지(`✨ 지난달 대비 +27.5km 🔥` / `-X.Xkm 🏃` / `지난달과 팽팽한 접전 ⚡️`)와 `동기간 N일차` 기준 배지 배치.
   - 설정(Settings) 화면에서 건강 연동 상태 및 권한을 관리하며, 대시보드에서는 **Pull-to-Refresh** 제스처로 간편하게 최신 기록 동기화.

#### [기능 F-104] 최근 달리기 피드 (Recent Logs)
- 당월 등록된 세션을 최신순으로 상위 **7건** 목록 렌더링.
- **[v1.0.7] 4대 핵심 지표 중심의 미니멀 UI 개편**:
  - 불필요한 기기명(예: "이준성의 Apple..."), 출처 라벨("애플 건강", "수기 직접 입력"), 기여도(`+6.2%`) 등의 군더더기 정보를 완전히 제거.

    - 사용자가 200~1,000km 범위에서 슬라이더로 자유롭게 직접 조정 가능.
  - **착용 시작일 기준 완전 자동 누적 & 로테이션 지원**: 매 세션마다 신발을 고르는 번거로움 없이 현재 주력 신발로 자동 누적되며, 2켤레 이상을 번갈아 신는 로테이션 러너는 세션 상세 카드나 수동 입력 창에서 1초 만에 착용 신발을 변경하여 각 신발별 마일리지를 독립적으로 정밀 집계.
  - **4단계 수명 상태 모니터링**: 🟢 `최상 (0~60%)`, 🟡 `적정 (61~85%)`, 🟠 `교체 준비 (86~100%)`, 🔴 `수명 완료 (100% 초과)`.
  - **은퇴 보관함(명예의 전당)**: 새 신발 교체 시 이전 신발의 최종 누적 주행 거리를 확정 보관하고 히스토리 관리.
- **[기능 F-402] 화면 테마 모드 선택**:
  - `다크 모드 (기본)`, `라이트 모드`, `시스템 설정 일치` 3가지 모드 선택 옵션 제공
- **[기능 F-403] 애플 건강 (HealthKit) 연동 관리**:
  - 건강 앱 접근 권한 승인 상태 표시 및 권한 재요청 링크 / 최근 동기화 시각 안내
- **[기능 F-404] 앱 정보 및 데이터 관리**:
  - 현재 앱 버전 동적 표시 (`Bundle.main`의 `CFBundleShortVersionString` 및 빌드 번호 연동, 예: `v1.3.0 (1)`), 개발자 정보 표시
  - **앱 버전 터치 시 릴리즈 노트 팝업**: 버전 행을 탭하면 v1.3.0 러닝화 트래킹 & 로테이션 지원 등 버전별 상세 업데이트 히스토리를 깔끔하게 확인할 수 있는 릴리즈 노트 바텀 시트(`ReleaseNotesModalView`) 탑재
  - 로컬 달리기 기록 전체 초기화 옵션 (경고 팝업 후 초기화)

## 6. iOS 특화 기능 (iOS 18 / iPhone 16)

### 6.1 홈 화면 바탕화면 위젯 (WidgetKit - Medium 2x4 단일 집중)
앱을 실행하지 않아도 아이폰 홈 화면에서 대시보드의 메인 히어로 카드(F-102)를 그대로 옮겨놓은 듯한 완벽한 시각적 일체감을 제공합니다.

- **지원 규격**: `.supportedFamilies([.systemMedium])` (바탕화면 전용 단일 집중)
- **위젯 레이아웃 및 세부 구성 (F-102 히어로 카드 1:1 이식)**:
  1. **좌측 영역 (원형 프로그레스 링)**:
     - 대시보드와 동일한 오렌지-앰버 그라디언트 100km 프로그레스 링
     - 링 중앙 대형 누적 거리 수치 (`68.0 km`), `/ 100 km`, 달성률 배지 (`68% 달성`)
  2. **우측 영역 (2단 정보 카드)**:
     - **이번 달 평균 페이스 카드**: 대형 페이스 수치 (`5:30 /km`), 러닝 횟수 및 총 러닝 시간 (`12회 러닝 • 총 6시간 14분`)
     - **이번 달 평균 심박수 카드**: 대형 심박수 수치 (`152 bpm`), 심박 상태 가이드 (`적정 유산소 심박 구간 🏃`)
- **데이터 갱신 및 화면 테마 실시간 동기화**:
  - `WidgetCenter.shared.reloadAllTimelines()`를 통해 앱에서 기록 추가, 건강앱 동기화, 또는 설정 변경 시 위젯이 즉각 갱신됨.
  - **[v1.2.2] 화면 테마 동기화**: 앱의 설정 테마(`다크`, `라이트`, `시스템 일치`)가 App Group을 통해 위젯으로 실시간 전달되어, 기기 설정과 무관하게 홈 화면 위젯도 앱과 동일한 테마(다크 딥그레이 / 라이트 순백색)로 자동 적응.

### 6.2 Apple HealthKit 연동 요건
1. **권한 요청 항목**:
   - `HKQuantityType.quantityType(forIdentifier: .distanceWalkingRunning)` (Read)
   - `HKObjectType.workoutType()` (Read)
2. **동기화 로직**:
   - 중복 누적 방지를 위해 각 `HKWorkout`의 `UUID`를 로컬에 캐싱 및 대조.
   - 워크아웃의 `totalDistance` 값을 추출하여 km 단위로 환산 후 `RunSession` 생성.

## 7. 비기능적 요구사항 (Non-Functional Requirements)

1. **퍼포먼스 & 응답성**:
   - 앱 콜드 스타트(Cold Start) 실행 시간 **0.8초 이하**.
   - 캘린더 셀 탭 및 탭 전환 간 프레임 드랍 0건 (60fps/120fps ProMotion 유지).
2. **오프라인 우선 (Offline-First)**:
   - 서버 통신 없이도 로컬 `SwiftData`만으로 100% 독립 동작 보장.
3. **데이터 보호 & 개인정보**:
   - GPS 위치 좌표를 서버나 외부로 전송하지 않음 (Apple HealthKit의 읽기 데이터는 기기 로컬 샌드박스 내부에서만 소비).
